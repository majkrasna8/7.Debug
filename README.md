--Debug
1. **Open in Android Studio:**
   - Launch Android Studio.
   - Select **File > Open...** and navigate to the project directory.

2. **Build & Run:**
   - Wait for Gradle sync to complete.
   - Click **Run** (`Shift + F10`) or **Debug** (`Shift + F9`).

---

3 **🐞 Debugging Exercises Included**

This project is configured for practicing Android Studio Debugger tools:

1. **Breakpoints:** Setting breakpoints in `MainActivity.java` within the `compute()` method.
2. **Stepping Controls:** Using **Step Over** (`F8`), **Step Into** (`F7`), and **Step Out** (`Shift + F8`).
3. **Conditional Breakpoints:** Halting execution on specific inputs (e.g., `(operandOne == 42) || (operandTwo == 42)`).
4. **Variable Inspection:** Modifying variables dynamically during execution using **Set Value** (`F2`).
5. **Logcat Analysis:** Tracking runtime exceptions such as `NumberFormatException`.
